## 📘 JavaScript Advanced

This project contains a series of JavaScript exercises focused on more advanced concepts such as closures, DOM manipulation, asynchronous behavior, context binding, and performance measurement.

### ✅ Files and Descriptions

#### 0-welcome.js
- Logs a welcome message using a nested function structure.

#### 1-nested_functions.js
- Demonstrates nested functions and scope.

#### 2-function_me.js
- Creates closures that return a greeting message with a given name.

#### 3-classrooms.js
- Uses closures to store and return a list of student seat numbers.

#### 4-math.js
- Builds `addBy` and `divideBy` closures.
- Includes reusable math operations as function factories.

#### 5-mode.js
- Applies different styles to the document using closure-based theme functions.
- Dynamically creates and binds buttons to trigger different visual themes.

#### 6-hogwarts.js
- Implements a class with private fields and methods.
- Includes methods for rewarding and penalizing a student, tracking their score.

#### 7-timeout.js
- Uses `setTimeout` and the event loop to measure execution time at the end of the call stack.

#### 8-payment.js
- Simulates an order and payment processing flow.
- Demonstrates function composition.

#### 9-prime.js
- Returns a constant value for the number of primes between 2 and 100.

#### 10-prime.js
- Measures execution time for running the prime function 100 times using `performance.now()`.

#### 11-prime.js
- Uses `setTimeout` to defer the prime function execution, ensuring it's run at the end of the event loop.

#### 12-room_area.js
- Demonstrates how to bind a method to an object to retain the `this` context.

#### 13-bind_user.js
- Binds a user method with a predefined welcome string.
- Demonstrates the use of `.bind()` with a custom message.

#### 14-wikipedia.js
- Uses `XMLHttpRequest` to fetch data from Wikipedia.
- Extracts the summary of the "Stack Overflow" article and injects it into the DOM.

### ⚖️ Key Concepts Practiced
- Closures
- Event Loop and `setTimeout`
- Performance timing with `performance.now()`
- DOM manipulation
- Object method binding with `.bind()`
- Working with XHR requests (AJAX)
